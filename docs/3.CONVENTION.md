## Conventions de nommage et de développement

#### Nommage des ressources Scaleway

- Instances : `lutice-gr<number>-<client_name>` (ex : `lutice-gr2-lerebours`)
- Security Groups : `lutice-sg-default`
- Tags : `lutice`, `grouphack:<number>`, `client:<client_name>`, `offer:<offer_type>`

#### Branches Git

| Branche | Usage |
|---------|-------|
| `main` | Branche stable, code validé et testé |
| `develop` | Branche d'intégration, merge des features |
| `feature/<pôle>/<description>` | Branches de développement (ex : `feature/portail/formulaire-souscription`, `feature/ansible/role-docker`) |
| `hotfix/<description>` | Correctifs urgents |

#### Messages de commit

Format recommandé : **Conventional Commits**

```
<type>(<scope>): <description courte>

[corps optionnel]
```

Types : `feat`, `fix`, `docs`, `refactor`, `test`, `chore`, `ci`

Exemples :
- `feat(portail): ajout du formulaire de souscription`
- `feat(ansible): rôle docker fonctionnel`
- `fix(api): correction du parsing de la réponse Scaleway`
- `docs: ajout du schéma d'architecture`
